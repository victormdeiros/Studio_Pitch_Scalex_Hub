    Publicar no GitHub Pages

    A ordem e os textos são gravados em content.json no repositório. O GitHub Pages republica o link em cerca de um minuto. O token fica salvo apenas neste navegador e nunca é enviado para outro lugar.

    Crie um token fine-grained em github.com/settings/personal-access-tokens, dê acesso apenas a este repositório e marque Contents: Read and write.
